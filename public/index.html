Prove who you are — without revealing who you are.

A zero-knowledge proof lets a prover convince a verifier that a statement is true while revealing nothing beyond that truth. This app implements three ZK protocols for anonymous authentication over a network, using a 2048-bit safe-prime group. Your secret key x is generated only in your browser and is never transmitted.

Why it works

Schnorr Σ-protocol

Prover knows x with y = gx.

  • Commit: r ← Zq, t = gr
  • Challenge: c ← Zq
  • Respond: s = r + c·x mod q
  • Verify: gs = t·yc

Correctness: gr+cx = gr(gx)c. A simulator can fake a transcript for any c by choosing s first — hence zero-knowledge. Special soundness extracts x from two accepting transcripts with different challenges.

Fiat–Shamir

Replace the verifier's random challenge with a hash of the commitment (and public inputs), making the proof non-interactive and directly verifiable: c = H(g, y, t, msg).

Binding the hash to a single-use nonce prevents replay attacks.

AOS ring signature

For ring y0..n-1 and real signer k:

  • Real index: tk = gr
  • Others i≠k: pick random ci, zi, set ti = gzi·yi−ci
  • c = H(msg, y·, t·), then ck = c − Σi≠k ci
  • zk = r + ck·xk
  • Verify: recompute all ti, check Σci = H(…)

All simulated pairs are uniform, so the signature distribution is identical for every choice of signer — anonymity is unconditional.
